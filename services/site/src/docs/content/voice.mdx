title: "Voice"
---

Desktop voice calls can run on Codex realtime instead of GPT-Live. OpenCode
starts the [Codex CLI](https://github.com/openai/codex)'s `codex app-server` on
the server and uses its sign-in, so a ChatGPT plan works without an OpenAI API
key. This is experimental and behind the `codex_voice` flag, which is on in
local and dev builds.

Configure it in any [OpenCode configuration file](/config):

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "voice": {
    "codex": {},
  },
}
```

The server needs the Codex CLI and a sign-in. Run `codex login` once on the
machine that runs OpenCode.

## How a call works

1. Desktop sends its WebRTC offer to the server, which starts an ephemeral Codex
   thread and its realtime voice. Audio flows directly between Desktop and
   OpenAI.
2. When you ask for something, the voice delegates it to the Codex agent of that
   thread.
3. The agent works only through OpenCode's voice tools, such as listing,
   reading, opening and messaging sessions. Desktop runs those tools, just as it
   does for GPT-Live. The agent has no shell, files or web of its own.
4. The voice speaks the agent's answer. Replies that sessions send later are
   spoken too.

## Options

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "voice": {
    "engine": "codex",
    "codex": {
      "command": "/Users/me/.local/bin/codex",
      "args": ["--disable", "hooks"],
      "env": { "CODEX_HOME": "/Users/me/.codex-voice" },
      "model": "gpt-6.1-sol",
      "reasoning_effort": "low",
      "config": { "model_verbosity": "low" },
      "realtime": {
        "version": "v3",
        "voice": "cove",
        "ack_filler": true,
      },
      "instructions": {
        "append": "Answer in Japanese.",
      },
    },
  },
}
```

| Field                             | Default          | Purpose                                                                                     |
| --------------------------------- | ---------------- | ------------------------------------------------------------------------------------------- |
| `engine`                          | `codex` when set | `codex` or `gpt-live`. Without it, Desktop uses Codex whenever `voice.codex` is set.        |
| `codex.command`                   | `codex`          | Codex CLI executable. OpenCode also looks in `~/.local/bin`, Homebrew and `/usr/local/bin`. |
| `codex.args`                      | none             | Arguments after `codex app-server`, such as `-c key=value`, `--enable` or `--disable`.      |
| `codex.env`                       | none             | Extra environment variables for the app-server process.                                     |
| `codex.cwd`                       | home directory   | Working directory of the Codex thread behind a call.                                        |
| `codex.model`                     | Codex config     | Model of the Codex agent that handles delegations.                                          |
| `codex.reasoning_effort`          | `low`            | Reasoning effort of that agent.                                                             |
| `codex.config`                    | none             | Codex config overrides for the call's thread, with dotted Codex config keys.                |
| `codex.realtime.version`          | `v3`             | Codex realtime protocol. `v3` is GPT-Live with Codex delegation.                            |
| `codex.realtime.model`            | Codex's default  | Realtime voice model.                                                                       |
| `codex.realtime.voice`            | Codex's default  | Output voice. The voices depend on the version; v3 has `cove`, `juniper` and others.        |
| `codex.realtime.ack_filler`       | Realtime default | Let the voice acknowledge a request while the agent works (v3).                             |
| `codex.realtime.startup_context`  | `false`          | Add Codex's own workspace and recent-thread context to the voice prompt.                    |
| `codex.realtime.reasoning_status` | `false`          | Relay the agent's reasoning summaries to the voice as quiet context (v3).                   |

The app-server keeps running while the server does. A change to `command`,
`args` or `env` starts a new process for the next call; the other fields apply
to the next call as soon as you save.

Codex reads its own `~/.codex/config.toml` too, including hooks and plugins.
Disable what a voice call shouldn't run with `args`, or point `CODEX_HOME` at a
separate Codex home in `env`.

## Instructions

OpenCode gives the voice and the agent instructions written for Desktop. Replace
or extend them under `voice.codex.instructions`:

| Field       | Purpose                                                                       |
| ----------- | ----------------------------------------------------------------------------- |
| `voice`     | Replaces the system instructions of the realtime voice, the part you talk to. |
| `delegator` | Replaces the base instructions of the Codex agent that drives OpenCode.       |
| `append`    | Adds developer instructions for the agent and keeps OpenCode's defaults.      |
| `start`     | Developer instructions the agent gets when a call starts.                     |
| `end`       | Developer instructions the agent gets when a call ends.                       |

Prefer `append` for language or tone. Replacing `delegator` drops OpenCode's
rules for using its tools, such as when to open a session or only message it.
